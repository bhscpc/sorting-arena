# Sorting Arena

Sorting arena that lets you visualize 2 sorting algorithms and watch them face off!

### Deployed:

[https://bhscpc.github.io/sorting-arena]

## How to use:

0. Select your two sorting algorithms

1. Enter the size of the array you want to sort (between 1 and 1000).

2. Enter the speed of the sorting process (delay between each operation).

3. Click "Start Sorting" to begin the sorting process.
